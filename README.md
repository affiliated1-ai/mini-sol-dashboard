This is a simple trading dashboard to trade crypto / digitized assets.  The dashboard is based on a few indicators, and I am currently adding to it as I go.

How it works:

Just download the HTML file and run it (double click).  It opens in a browser and shows you the asset (SOL currently, but support is coming for other assets on Binance) .  

Suggested trading is based on the included indicators:

1.  CCI - Commodity Channel Index.  Rising CCI means a rising stock price .. its similiar to a short term volume trend indicator.
2.  Fisher Transform - its better and more sensitive than the MACD, imo.  Blue over red, Bullish .. red over blue, bearish.
3.  Ichumoku Cloud - Tenkhan-sen (Ichomoku is made of of varying Moving Averages anyway, the Tenkhan-sen is one of the moving averages that I think is relevant for trading - but everybody has their bias)
4.  Volume Weighted Moving Average - think of it like a floor.  When price jumps of the floor, agressively, good sign .

As mentioned, this tiny dashboard is based on Binance API Calls - pretty simple to put together, especially nowadays.

Me , personally, I have 10+ years of trading experience, so this is meant to be a shortcut for beginners.  Just follow these indicators.  BTW, you know you can be bullish, you can be bearish - so use these 
indicators and trade accordingly.

Happy Trading :)
